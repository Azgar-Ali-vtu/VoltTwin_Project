What this scorecard means

Verification asks whether the numerical implementation behaves as intended. Validation asks whether the model matches appropriate reference data. Credibility also considers calibration, uncertainty, reproducibility, and the limits of the evidence.

A low or partial score is not hidden. The course rubric specifically values evidence and explicitly stated gaps over unsupported claims.

System design
Twin architecture
The two data-flow arrows are essential: observation flows into the twin, and control flows back to the simulated asset.
Layer 01
Physical asset · simulated
48 V lithium-ion pack · thermal state · power load · cooling response
↓ Sensor telemetry
↑ Control command
Layer 02
Digital twin engine
Thermal model · state estimate · residual detector · fan controller · trust monitor
↓ State, residuals, alarms and evidence
Layer 03
Operator dashboard & evidence
Overview · simulation controls · telemetry · event log · credibility scorecard
Data flow into the twin

The simulated physical state generates a temperature measurement with configurable noise, bias or missing packets. The twin compares the measurement with its model estimate and computes residuals for monitoring.

Control flow back to the asset

The controller calculates fan duty from temperature. If trust drops below the configured threshold, the demonstration controller requests full cooling. This is illustrative software logic, not a certified battery-management system.
